Introduction to Cloud Computing

UNDERSTANDING THE TECHNOLOGY

What is Cloud Computing?

Cloud computing is a technology that allows people and organizations to access computing resources through the Internet instead of managing all hardware and software ib their own computers. These resources can include servers, storage, databases, networking, and software applications. Users can access services whenerver they need them and often pay only for the resources they use. Cloud computing also makes it easier to increase or decrease computing capacity based on denmand. For example, a company can host its website on a cloud platfoirm without purchasing and maintaining its own physical server. This approach helps organizations save time, improve flexibility, and make their applications available to users from different locations.

CLOUD SERVICES

Types of Cloud Services

Three commong service models in cloud computing.

01

IaaS

Infrastructure as a Service (IaaS)

Provides virtual computing resources such as servers storage and networking Users manage their operating systems and applications.

Example: Amazon EC2
02

PaaS

Platform as a Service (PaaS)

Provides a platform that allows users to develop, run, and manage applications without worrying about the underlying infrastructure.

Example: Google App Engine
03

SaaS

Software as a Service (SaaS)

Delivers software applications over the Internet, allowing users to access and use them through a web browser without installing or maintaining the software.

Example: Micorosoft Office 365
